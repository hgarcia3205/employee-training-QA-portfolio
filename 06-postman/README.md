# Employee Training Management QA Portfolio Project

## Overview

This project demonstrates a complete software quality assurance workflow using manual testing, API testing, and automated browser testing.

The project was designed to practice the same core activities commonly performed by a Quality Assurance / Tester:

- requirements analysis
- test planning
- manual functional testing
- negative testing
- boundary validation
- requirements traceability
- API testing
- automated regression testing
- evidence collection
- final test reporting

## Applications and Tools

### Applications Under Test

- OrangeHRM Open-Source Demo
- DummyJSON Users API

### Tools

- Postman
- Playwright
- Visual Studio Code
- Git
- GitHub
- Windows 11
- Chromium / Microsoft Edge
