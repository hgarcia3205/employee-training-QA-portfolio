# Employee Training Management System

## Functional Requirements

### REQ-001 — User Authentication
The system shall allow an authorized user to log in using a valid username and password.

### REQ-002 — Invalid Authentication
The system shall reject invalid usernames or passwords and display an appropriate error message.

### REQ-003 — Employee Creation
An authorized user shall be able to create a new employee record.

### REQ-004 — Required Employee Fields
The system shall require a first name and last name before creating an employee record.

### REQ-005 — Employee Search
An authorized user shall be able to search for an existing employee.

### REQ-006 — Employee Update
An authorized user shall be able to modify an existing employee record.

### REQ-007 — Employee Deletion
An authorized user shall be able to delete an employee record.

### REQ-008 — Training Assignment
An authorized user shall be able to assign training to an employee.

### REQ-009 — Training Completion Status
The system shall display the completion status of assigned training.

### REQ-010 — Access Control
Unauthenticated users shall not be able to access protected employee information.
